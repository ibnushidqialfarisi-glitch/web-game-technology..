// 01 · BRIEFING

APA ITU GAME TECHNOLOGY?

Ilmu & seni di balik penciptaan pengalaman interaktif — dari baris kode hingga piksel di layar.

Game Technology adalah gabungan ilmu komputer, matematika, fisika, dan seni visual untuk menciptakan dunia interaktif yang bisa dimainkan.

Mencakup game engine (Unity, Unreal), rendering grafis, physics, audio, hingga netcode multiplayer — semua bekerja sinkron di balik layar.

Dari Pong 2D tahun 1972 hingga dunia open-world fotorealistis hari ini, evolusinya luar biasa. Ini adalah industri hiburan terbesar di planet ini.

// 04 · MISSION LOG

EVOLUTION TIMELINE

Perjalanan teknologi game — dari piksel hingga realitas virtual.

1972 · PONG

Game komersial pertama populer — 2D sederhana, fisika pantulan bola dasar.

1993 · 3D RENDERING

DOOM mempopulerkan grafis pseudo-3D lewat teknik raycasting inovatif.

2005 · SHADER MODERN

GPU programmable memungkinkan pencahayaan real-time & efek visual realistik.

2013 · KONSOL GEN 8

PS4 & Xbox One menghadirkan 1080p 60fps dan dunia terbuka masif.

2018 · RAY TRACING RTX

NVIDIA RTX memperkenalkan ray tracing real-time untuk pencahayaan sinematik.

2023+ · AI GENERATIF

DLSS, AI generatif, dan cloud gaming mengubah cara game dibuat & dimainkan.
